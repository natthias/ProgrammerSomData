ADD: pops the top 2 values on the stack and puts the result of adding them on top of the stack represented with a 10 in the byte code
CSTI: pushes integer constant i on the stack represented with a 0 in the byte code
NIL: NIL pushes #0 to the stack and CSTI pushes 0 on the stack
IFZERO: Checks if the upper most value on the stack is 0 if true jumps to given instruction else moves on
CONS: Puts a pointer on the stack that points to a 2 word block in the heap
CAR: Treats the top most value on the stack as a pointer to a block in the heap and puts the first word from that block on the top of the stack
SETCAR: takes two value from the stack, treats the second value from the top of the stack as a pointer to a block on the heap, and updates the first word in that block with the top most value of the stack.
